# 插件安装与更新

Extend 控制中心管理插件列表、主开关、右侧入口以及安装更新。每个插件的功能设置位于它自己的面板。原始脚本面板底部仅保留“打开 Extend 菜单”按钮，在入口隐藏时也可恢复并直接打开。加载、启停、删除和更新均从 Extend 菜单执行。

Lua 与 JS 各有独立的 17 项功能许可。MCP 主开关停止/重启宿主内监听器，重新开启会更换 token；每项工具可独立关闭，关闭后从 tools/list 移除且 tools/call 拒绝执行。官方编辑器 provider 使用的内部 Lua 原生适配不受用户脚本总开关影响。

## 独立插件包

“安装新插件”选择 ZIP 或 `.sv2ext`；“从链接安装”接受 HTTPS 发布信息 JSON。插件包根目录或单层外包目录包含 `plugin.json` 和原生库；多平台清单见 [跨平台契约](CROSS-PLATFORM.md)。插件是宿主内原生代码，应选择可信发布者。

发布信息格式：

```json
{
  "id": "example.hello",
  "version": "1.0.1",
  "downloadURL": "https://example.com/hello-1.0.1.zip",
  "sha256": "64位小写十六进制SHA256"
}
```

首次通过链接安装会记录发布信息地址；也可在包的 `plugin.json` 中提供 `updateURL`。更新检查只读取配置的独立插件来源。没有来源时会明确提示，不会声称全部为最新版。MCP、Lua、JS 内置适配随 Loader 更新，不接受独立包覆盖。

下载、ZIP 解析、SHA256 校验和安装队列均在宿主内执行，不运行外部解包进程。限制：下载 8 MiB、展开 32 MiB、单文件 16 MiB、最多 256 项；拒绝越界路径、链接、设备、重复文件和不匹配的本机架构。版本目前接受一至三段非负整数，不支持 prerelease 后缀。

删除独立插件先排入队列，重启前可以取消；重启后将原包移至备份，不永久擦除。删除与待安装更新相互排斥，文件外部变化时保留原样。

安装先排入队列，重启时才应用，不会卸载正在使用的 DLL/dylib。已有包保留备份，并用事务记录恢复中断。应用更新需要 Loader 的独占 profile lease；其他宿主仍使用同一 profile 时保持队列。独立包可设置“随宿主启动（重启生效）”；这与插件自身提供的即时功能开关不同，已加载的原生代码保留至宿主退出。

持久启动联网 guard 用于崩溃恢复时在下一次宿主 main 前请求阻断。损坏或不安全的策略文件按阻断处理；它不等于完整联网隔离验证。

上述宿主内队列安装器目前为 macOS 后端。Windows 使用 `loader/windows/install.ps1 -PluginPackage` 在宿主退出后安装原生包，保留升级备份；宿主内下载、排队更新与独立插件删除尚未适配。Windows 设置持久化在 profile，侧栏展开时覆盖右侧区域，收起后恢复工作区。Settings Probe 是开发诊断 fixture，不随正式安装注册为插件。
