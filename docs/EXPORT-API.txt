WAV 混音导出 API

MCP、Lua 和 JavaScript 使用宿主内同一编辑器 provider。原生适配器未就绪时，导出方法不会出现在能力列表中。

方法：
exports.snapshot({}) -> guard、15 秒有效期、busy、pending。
exports.start({guard,outputPath,channels,sampleRate,bitDepth}) -> jobId、state。
exports.status({jobId}) -> running、cancelling、completed、cancelled 或 failed。
exports.cancel({jobId}) -> 请求取消；继续查询 status，直到确认终态。

MCP 名称：sv_export_snapshot、sv_export_wav、sv_export_status、sv_export_cancel。
outputPath 必须是父目录已存在的绝对 .wav 路径；已有目标不会被覆盖。
channels 为 1 或 2，bitDepth 为 16、24 或 32。Windows 支持 44100、48000、96000 Hz；macOS arm64 还支持 88200 Hz。仅支持 WAV 混音。

先获取快照，再用当前工程的新 guard 启动。轮询 status 并保持工程打开。导出使用目标目录旁的独立暂存目录；只有原生渲染结束、WAV 格式验证通过且目标仍不存在时才发布。取消或失败不发布最终文件，暂存文件保留供检查。configRestored 表示原工程的导出设置已恢复；发生恢复失败或工程切换时应检查状态。

Windows 使用原生 Render 控件配置和启动，等待原生渲染生命周期结束后恢复设置。macOS 在原生启动调用期间临时配置并恢复设置。各平台按实际原生能力公布工具；无外部常驻编辑器管理进程。

JS（在官方脚本 main 中，OUTPUT_WAV 为调用方提供的路径）：
var Extend = eval(Duktape.enc('opensv2.module.v1', ''));
Extend.exports.snapshot(function (error, snapshot) {
  if (error) { SV.print(error.code); return; }
  Extend.exports.start({guard:snapshot.guard, outputPath:OUTPUT_WAV,
    channels:1, sampleRate:48000, bitDepth:24}, function (error, job) {
    if (error) { SV.print(error.code); return; }
    function poll() {
      Extend.exports.status(job.jobId, function (error, status) {
        if (error) { SV.print(error.code); return; }
        if (status.state==='running' || status.state==='cancelling') {
          SV.setTimeout(100,poll); return;
        }
        SV.print(JSON.stringify(status)); SV.finish();
      });
    }
    poll();
  });
});

Lua（设置 package.path 并 require('sv2_extend') 后）：
Extend.exports.snapshot(function(snapshot, err)
  if err then SV:print(err.code); return end
  Extend.exports.start({guard=snapshot.guard, outputPath=OUTPUT_WAV,
    channels=1, sampleRate=48000, bitDepth=24}, function(job, err)
    if err then SV:print(err.code); return end
    local function poll()
      Extend.exports.status(job.jobId, function(status, err)
        if err then SV:print(err.code); return end
        if status.state=='running' or status.state=='cancelling' then
          SV:setTimeout(100,poll); return
        end
        SV:print(status.state); SV:finish()
      end)
    end
    poll()
  end)
end)
