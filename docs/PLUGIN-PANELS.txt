Extend 原生分类与插件面板（macOS，0.8.1 起）

用户界面
- 右侧工具栏中，设置齿轮下方是独立的 Extend 分类（描边扩展图标）。
- Extend 管理入口显示、已注册插件、安装/删除/更新和“显示右侧面板入口”；功能设置位于各插件自己的面板。
- 每个插件注册 id 都有独立的右侧工具栏入口及面板，可以同时展开多个插件面板。
- 隐藏入口会关闭对应面板，但不卸载插件或停止 MCP；恢复后可再次打开。
- 运行中注册会新增入口；注销会关闭面板并移除入口。插件状态、面板行和按钮通过 Loader API 更新。
- 内置布尔开关点击即保存；第三方复合表单显式保存。按 schema 验证并一次写入，失败、过期 generation 不会部分保存。

插件包
放在所选数据目录的 plugins/<包目录>/，例如：
  plugin.json
  plugin.dylib
plugin.json：
  {"schema":1,"id":"example.plugin","name":"Example","version":"1.0","nativeLibrary":"plugin.dylib","enabled":true}
Loader 启动时扫描 plugin.json，使用 dlopen 在宿主内加载并调用 loader_plugin_init_v1。
启动时扫描包目录；新增/更新二进制包需重启 Loader。已加载插件可在运行中动态注册/注销多个面板 id。
不提供不安全的热卸载：进入过初始化函数的模块均保留到宿主退出，包括初始化报告失败的模块。
包目录、manifest、库要求当前用户拥有的普通文件/目录；绝对路径、越界路径和最终库符号链接被拒绝。
无效包不会执行库构造器。重复 manifest id 只加载第一个。
未主动注册同名 UI 的包会获得一个显示初始化结果的默认面板。

抽象 API
loader_api.h 的 append-only register_plugin_ui / update_plugin_ui / unregister_plugin_ui。
插件检查 struct_size 和 LOADER_CAP_PLUGIN_UI；注册、更新、注销及事件回调均在主线程。
描述：id/name/version/status，sidebar{title,rows}，settings[]。
行：{type:"label",text:"..."} 或 {type:"button",id:"refresh",text:"刷新"}。
设置：boolean、choice（choices 字符串数组）、integer（minimum/maximum）、text。
注册后及设置保存后收到 kind:"settings",settings:{...}；按钮收到 kind:"action",action:"..."。
回调 JSON 仅在调用内有效。插件在释放 owner_context 前注销；隐藏不触发卸载。
最多同时注册 32 个 UI id；包含公开内置扩展，插件包可以注册多个独立 id。
Lua 使用月球标志风格、JS 使用方框 JS、MCP 使用连接节点、Extend 使用扩展网格；跟随宿主灰色/选中绿色着色。其他插件暂用通用插件图标。
此版本提供声明式原生标签、按钮、设置控件，不开放任意外部网页或外部管理窗口。

数据与生命周期
preferences/extend-ui.json 保存显隐和设置；这些是普通插件配置，不应放账号密码。
切换到新数据目录时一并复制 preferences；已有目标不合并、不覆盖，原目录保留。
原生面板类型不在宿主内置反序列化表中。下次启动前，仅移除 UILayout 内自己的 OpenSV2ExtendPanel 节点；
原 settings.xml 字节完整备份到 preferences/layout-backups。其余面板及设置保留。
重启后按插件重新创建入口；已展开的插件面板不会自动恢复，显隐和插件设置会恢复。
仅在受支持的 SV2 2.3.0 arm64、托管副本和隔离宿主数据目录中启用原生分类；UUID/代码摘要不匹配时拒绝接入。
使用原生分类注册对象及数据 vtable 接入，不修改官方安装，也不改写可执行代码段。
所有 Loader、MCP、Lua/JS 和插件运行时均驻留宿主，无额外常驻管理进程。

范围
这是公开 Loader 插件 UI/包接入能力。
本版本没有宣称整宿主联网静默已验证，也没有启用未完成的真实账号切换。

0.9.1 功能设置与管理
- 原版“脚本”面板底部仅保留“打开 Extend 菜单”按钮，隐藏主入口后仍可恢复打开。
- 插件安装、删除、启停、更新都在 Extend 菜单中。删除独立插件在重启后移至备份，可在重启前取消。
- Lua 与 JS 的总开关、17项函数许可、运行详情位于各自面板。
- MCP 总开关和各项工具开关位于 MCP 面板；关闭总开关停止监听，重开轮换本地凭据。
- 关闭用户 Lua Extend 不关闭 MCP 使用的内部编辑器 provider。
- 内置插件随 Loader 更新；独立原生包的启动开关、删除须重启生效，不热卸载模块。
- 原版程序安装不被修改，控件仅在受支持的托管宿主副本内出现。

SDK v1 在 stop_local_json 后追加持久启动 guard 与 profile kernel lease。
完整宿主联网覆盖仍未验证；guard应用与lease成功不是隔离验证receipt。
