# 声库实时接口验证

0.9.10 的已安装 Loader 副本经过真实 SV2 2.3.0 arm64 回归。测试保留安装版 Core 和公开插件，使用独立偏好域、新建隔离 profile 与空白工程，不迁移原始数据。通过驻留 MCP 调用内部原生 Lua 适配器，完成 100 轮声库/工程读取、两个可用声库之间 16 次选择与身份读回；同一宿主 PID 保持存活，测试结束后退出。

复现：

```sh
python3 loader/macos/run-installed-voice-regression.py
```

需要本机安装 Extend Loader 和至少两个可用声库。测试驱动会复制安装版启动器，改变副本的偏好域并临时重签；不会替换其中的 Core。若等待或断言失败，保留同一测试宿主供检查，不自动重启；本地 work 下记录其 PID 与隔离目录。成功后退出该宿主并移除本次偏好域。

该回归不等于用户 Lua/JS 脚本直接调用验收，也不覆盖 WAV 导出、插件功能开关、账号切换或完整网络隔离。原安装入口的生命周期和模块归属由独立的安装验证覆盖。

## 官方用户脚本入口

另一个真实宿主中，从官方“脚本”菜单分别运行 Lua 和 JavaScript 验收脚本，均通过本语言的公开 facade 完成声库列表、当前声库读取、切换、身份读回和导出快照。返回的运行时 PID 与测试宿主一致，mainThread=true、usesFilesOrPipes=false。测试结束后宿主已退出。Lua 使用安装包内的模块，JS 使用宿主注册的原生模块入口；没有以 MCP 响应冒充用户脚本结果。

复现准备与结果收集：`python3 loader/macos/run-installed-script-regression.py`。启动后，在同一宿主的“脚本 → Extend Acceptance”菜单运行两个 Voice Acceptance 脚本。驱动等待两种语言的诊断输出，成功后退出其自身宿主。测试会改变独立空白工程的声库，不保存工程。该检查覆盖导出快照，不代表已完成真实 WAV 渲染、取消和输出保护验收，也不覆盖功能开关或账号隔离。
